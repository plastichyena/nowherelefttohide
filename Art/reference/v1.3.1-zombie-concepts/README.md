# v1.3.1 Zombie concept references

These generated originals are retained at the user's request as future
art-direction and regeneration references. Only the 256px derivatives under
`public/assets/board/units/` are loaded by the board registry or counted toward
the 3 MiB runtime PNG budget.

- `zombie_original_concept.png`: first single-Zombie concept; retained but not
  currently used by the runtime.
- `horde_zombie_original_concept.png`: original three-Zombie concept; adopted
  as the source for the normal `zombie` runtime asset after visual review.
- `horde_zombie_swarm_source.png`: later twelve-Zombie swarm in the same style;
  adopted as the source for the `hordeZombie` runtime asset.

The adopted concepts use stylized comic-painted injury detail. Keep future
revisions non-photorealistic and no more graphic than these approved sources.
