Nowhere Left to Hide — Agent API

The game page exposes window.NLTH for a browser JavaScript agent. This is an in-memory developer bridge, not an HTTP API.

v1.4.3 contract

App/Release 1.4.3 uses Game Rules / GameState / Config 2.3.0, Fixed Map fixed-31x31-v2, Save Format 8, Agent / Observation / Browser Bridge API 5.0.0, Artifact Schema 4.0.0, and Checkpoint / Session Schema 1.0.0. Observations expose Ground/Aerial visibility, visible enemies, the latest 50 important public site events, Horde warnings, economy, legal previews, supply, and Core-generated candidates. Future random draws and hidden enemy state are never exposed.

Legal actions may include SetPowerSupply, BuildConstructibleFacility, BuildCheckpoint, RelocateCheckpoint, and ActivateCheckpoint. Infection suppression is an engine-owned End Turn consequence; SuppressInfection is not public. Older saves, replays, and artifacts are rejected without conversion, deletion, overwrite, or state change.

v1.4.3 rules visible to agents

  • Tiles expose Plain/Forest/Mountain terrain, road and urban overlays, weighted movement cost, terrain defense, current player visibility, and playerOccupancyAllowed. The outer 120-hex Horde Spawn Reserve has player occupancy disabled: Player Units, Player facilities, and Checkpoints cannot enter, stop, or be placed there, while Zombie movement, attacks, damage, interception, and attacks against visible Zombies remain legal.
  • Enemy arrays contain only visible normal and Horde Zombies. Hidden positions, IDs, target memory, and exact spawn coordinates are not exposed through observations, legal actions, events, or the bridge.
  • Player Units, the Capital (radius 5), owned facilities, and Active checkpoints provide Ground Vision. Forest and Mountain are visible blockers and hide Hexes beyond them. Powered Civilian Drone Bases provide terrain-ignoring Aerial Vision. Human UI and Agent API consume the same Core coverage sets.
  • Fixed Waves spawn at Turn 5 (1 direction, 2/3 Horde/Normal), Turn 10 (2, 1/4), Turn 20 (1, 4/6), Turn 35 (3, 2/6), and Turn 50 (4, 4/7 Final). Totals are Horde 30 / Normal 63; Final is Horde 16 / Normal 28. Warning Lead is 2 turns. Spawn Group IDs, exact positions, and hidden counts are never public.
  • Initial Normal Zombies use 12 fixed positions. A fallen site converts each 5 actually infected people into one Normal Zombie, up to 6 per resolution, on empty passable adjacent Hexes. Generated occupancy and FIFO chains resolve immediately and atomically, but generated Zombies wait until the next Zombie phase to act normally.
  • importantSiteEvents exposes the latest 50 public infection onset, fall, spawn, immediate infection, chain, and Noise-respawn facts even off-screen. It never exposes generated Zombie IDs, exact Spawn Hexes, targets, or hidden Noise reactions.
  • At the next player-turn start, supplied surviving units recover 10% of max HP after attack, counterattack, interception, or suppression, and 20% after only moving, waiting, or taking no action. Out-of-supply units recover 0%; configured rounding is applied.
  • A human unit stationed at an infected location contains internal spread. With an unused attack and at least 1 carried Military Good after refill, automatic suppression consumes 1 in the infection phase after End Turn. At 0, the unit only contains spread and does not spend its attack. Police suppress without civilian damage; National Guard suppresses more but has civilian damage.
  • Each human unit exposes currentMilitaryGoods, maxMilitaryGoods, fixed consumption, distance-based attack costs, suppression cost, refill projections, and carried totals after fixed consumption, refill, and suppression. The removed global militarySupplyAvailable flag is not part of this contract.
  • A distance-1 attack consumes 1 carried Military Good when available. At 0, Police and National Guard can still make a distance-1 attack at effective attack 1 and 2 respectively without consumption. National Guard distance 2 requires and consumes 2. Each legal attackPreviews entry exposes distance, cost, projected balance, effective attack, and damage before/after terrain.
  • Unit observations expose baseRange, effectiveRange, and shortage reasons. National Guard distance 2 is legal only when its own carried Military Goods can pay the cost of 2.
  • Cities and Required facilities use 5 power per facility when eligible; without power their production/function stops while city administration and population remain. Farm/Civilian/Military Factory/Refinery/Drone Base have Power Mode required; Power Plant, Wind Power Plant, and Simple Farm have Power Mode none. There is no Boost mode or industrial boost field.
  • Police and National Guard have Movement 10 and individual Fuel pools. With Fuel above 0, each legal Move includes its normal exact Fuel cost and remaining Fuel. With Fuel 0, Emergency Movement provides Police 3 MP and National Guard 2 MP, using the same effective terrain cost while Fuel remains 0. Legal Move previews expose movementMode, effectiveMovementCost, and projected Fuel.
  • End Turn uses Fuel for Power first, then refills supplied units in Unit-ID round-robin order; same-turn Refinery output is not available. Separately, National Guard consume 1 carried Military Good, Military Factory output enters national stock, and supplied units refill carried goods in Unit-ID ascending round-robin order before automatic suppression.
  • Wind Power Plant provides 15 Electricity without Fuel, Vision 1, and Zombie Target Value 5 without civilian population. Wind, Simple Farm, and Civilian Drone Base publish their state, capacity, power, output/vision, supply, and distinct Zombie Target Value.
  • BuildConstructibleFacility builds Simple Farms or Civilian Drone Bases only on supplied empty Plain Hexes with no road, urban overlay, entrance, player unit, or visible Zombie. Build candidates are Core-derived and hidden Zombies never alter their legality.
  • Power uses turn-start Fuel only at Fuel 1 → Electricity 5, with no partial allocation. Order is Cities, permanent Farm/Civilian Factory, input-ready Military Factory, Refinery, then Drone Base; Simple Farm has no power demand.
  • strategicForecast exposes dependency contributors, current shortages, single points of failure, Guaranteed Defeat, and Fuel accounting. Public Artifact Metrics include power requested/supplied/unavailable/OFF turns, resource loss, Checkpoint queue capacity/throughput, fixed Wave and direction spawn/kill totals, and Final Horde progress without hidden IDs or coordinates. Checkpoints expose branch policy and currentPolicyTurns, queue totals, throughput, arrival ranges, and Queue Pressure (none, low, medium, high).
  • Each road branch exposes one Active post, zero or more Standby and Dormant posts, a structural fallback flag, branch policy, and its prepared-post limit. Only Active posts receive arrivals, provide supply, and provide checkpoint vision. Fallback considers capital-side Standby first, then Dormant, without revealing hidden-Zombie exclusions.
  • checkpointPositionCandidates contains every branch road tile or activatable post with actionType, branchId, optional checkpointId, position, legal, and a Core reasonCode. Use it instead of reconstructing legality.
  • Checkpoint candidates include projected radius, supplied/unsupplied hex and facility deltas, and newly buildable constructible Hex count. Hidden enemies neither block candidates nor appear through IDs, messages, or candidate differences.
  • Checkpoint policy belongs to the branch and follows its Active post. Policy details describe screening time, acceptance, infection chance, and infected share. Strict is a trade-off, not an unconditional best choice.
  • A Combat Noise event exposes its center, Human Unit type, and public class only. Police is medium; National Guard is large. Fallen permanent sites can respawn from Noise after combat. Exact radius, affected Zombie IDs/counts, Spawn Hexes, and Zombie Noise Targets are not public.

Available methods

getApiInfo(), reset(options?), getObservation(), getLegalActions(), step(action), isGameOver(), getResult(), and getRunArtifact().

Call getApiInfo() for machine-readable versions, schemas, the recommended order, and the complete minimal example. Every returned value is a JSON-compatible copy. The bridge never reads or writes localStorage, save codes, or the normal UI session.

Persistent AI Portable Sessions

The Browser Bridge is deliberately in-memory. The downloadable AI Portable package instead provides a persistent Session CLI with seven commands: new, status, step, save-checkpoint, list-checkpoints, load-checkpoint, and artifact. A step requires one legal action and a 1–500-code-point public decisionSummary. status resumes the same Active Session; load-checkpoint always creates a separately named child Session and never rewinds its parent.

Public Decision Log entries include the observation and legal actions before the choice, the input action and summary, acceptance/error, public events, and a hash-chain link. Save Format 8 private state exists only for deterministic resume. AI players must not inspect it or use hidden GameState, RNG, targets, or non-public configuration. Active corruption is never silently rolled back; explicitly list Checkpoints and branch from one. See PLAY_WITH_AI.md for commands and recovery guidance.

Minimal browser example

const api = window.NLTH;
const info = api.getApiInfo();
console.log(info.appVersion, info.rules);
api.reset({ seed: 1, agent: { id: 'browser-agent' } });
while (!api.isGameOver()) {
  const legal = api.getLegalActions();
  if (legal.length === 0) break;
  api.step(legal[0]);
}
console.log(api.getResult(), api.getRunArtifact());

Browser smoke check

Build the production bundle, then run the dependency-free static bridge smoke check:

npm run build
npm run test:browser-bridge

A real browser can additionally open the GitHub Pages game URL, evaluate window.NLTH.getApiInfo(), reset a seed, fetch observations and legal actions, correct an invalid action, then replay listed actions until Game Over and collect Result／Artifact. A winning run is not required for this smoke check.

External-agent checklist

  • Discover the bridge from this page and the game URL without UI clicks or query parameters.
  • Read API information, observation, and legal actions before choosing one action per step().
  • After an invalid action, read its error, choose a listed legal action, and continue until Game Over.
  • Collect the result and Browser Bridge artifact as a public play trace; Artifact Schema 4.0.0 stores fixed-map topology once and each trace entry refers to it by mapId. Public Wave/Warning/Site Event state and release Metrics remain available without exposing verificationEvents. Session artifacts can also carry Public Decision Log and lineage. Neither contains private GameState, Spawn Group IDs, exact hidden Spawn Hexes, or hidden chain of thought.

Not exposed

getState, LoadSnapshot, arbitrary code execution, file operations, save operations, local storage, network access, Batch execution, exact Noise Radius, and hidden Noise reactions are not part of the public bridge.
