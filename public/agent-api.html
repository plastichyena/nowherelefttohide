Nowhere Left to Hide — Agent API

The game page exposes window.NLTH for a browser JavaScript agent. This is an in-memory developer bridge, not an HTTP API.

v1.2.6 contract

App/Release 1.2.6 uses Game Rules / GameState / Config 1.2.1, Save Format 2, and Agent / Observation / Bridge 1.2.0. Observations include independent road branches and arrival schedules, checkpoint status and pools, supplied tiles, sector/radius information, action availability, and current recovery, suppression, production, and power forecasts. Future random draws are never exposed.

Legal actions may include BuildCheckpoint and RelocateCheckpoint. Infection suppression is an engine-owned End Turn consequence; SuppressInfection is not a public action and is rejected by the bridge. A branch without a checkpoint processes arrivals as unmanaged pass-through; operational checkpoints extend supply, while remnant, ruined, and abandoned sites do not. v1.2.5 saves are migrated in memory only; older saves, JSON, replays, and artifacts are rejected without conversion or overwrite.

v1.2.6 rules visible to agents

  • At the next player-turn start, supplied surviving units recover 10% of max HP after attack, counterattack, interception, or suppression, and 20% after only moving, waiting, or taking no action. Out-of-supply units recover 0%; configured rounding is applied.
  • A human unit stationed at an infected location contains internal spread. With an unused attack, the engine may automatically suppress at the infection phase after End Turn. Police suppress without civilian damage; National Guard suppresses more but has civilian damage.
  • Unit observations expose baseRange, effectiveRange, and a shortage reason. National Guard range is 2 normally and 1 when military supply is short.
  • Facility observations expose worker capacity (30 for production facilities), input/output estimates, power requirements or generation, stop reasons, and projected infection/overrun losses. Checkpoint observations expose containment and suppression forecasts.
  • Checkpoint policy details describe screening time, acceptance, infection chance, and infected share. Strict is a trade-off, not an unconditional best choice.

Available methods

getApiInfo(), reset(options?), getObservation(), getLegalActions(), step(action), isGameOver(), getResult(), and getRunArtifact().

Call getApiInfo() for machine-readable versions, schemas, the recommended order, and the complete minimal example. Every returned value is a JSON-compatible copy. The bridge never reads or writes localStorage, save codes, or the normal UI session.

Minimal browser example

const api = window.NLTH;
const info = api.getApiInfo();
console.log(info.appVersion, info.rules);
api.reset({ seed: 1, agent: { id: 'browser-agent' } });
while (!api.isGameOver()) {
  const legal = api.getLegalActions();
  if (legal.length === 0) break;
  api.step(legal[0]);
}
console.log(api.getResult(), api.getRunArtifact());

Browser smoke check

Build the production bundle, then run the dependency-free static bridge smoke check:

npm run build
npm run test:browser-bridge -- --dist=dist

A real browser can additionally open the game URL, evaluate window.NLTH.getApiInfo(), reset a seed, fetch observations and legal actions, then replay the returned action list.

External-agent checklist

  • Discover the bridge from this page and the game URL without UI clicks or query parameters.
  • Read API information, observation, and legal actions before choosing one action per step().
  • After an invalid action, read its error, choose a listed legal action, and continue until Game Over.
  • Collect the result and run artifact; the artifact contains replay inputs, not the private GameState or hidden chain of thought.

Not exposed

getState, LoadSnapshot, arbitrary code execution, file operations, save operations, local storage, network access, and Batch execution are not part of the public bridge.
