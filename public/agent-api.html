Nowhere Left to Hide — Agent API

The game page exposes window.NLTH for a browser JavaScript agent. This is an in-memory developer bridge, not an HTTP API.

v1.6.4 contract

App/Release 1.6.4 uses Game Rules / GameState / Config 14.0.0, Fixed Map fixed-51x51-v8, Save Format 21, Agent / Observation / Browser Bridge API 19.0.0, Artifact Schema 18.0.0, and Checkpoint / Session Schema 15.0.0. Observations expose Ground/Aerial visibility, visible enemies, the latest 50 important public site events, Wave progress, economy, legal previews, supply, Core-generated candidates, and production capacity. Future random draws, hidden enemy state, exact neutral-survivor counts and deadlines, and exact Screamer Noise radius are never exposed.

Legal actions may include SetPowerSupply, BuildConstructibleFacility, DecommissionConstructibleFacility, BuildCheckpoint, RelocateCheckpoint, ActivateCheckpoint, SetCheckpointPolicy, and TurnAwayCheckpointRefugees. Checkpoint policies are pass, normal, strict, and deny. Infection suppression is an engine-owned End Turn consequence; SuppressInfection is not public. v1.6.3-and-earlier Save codes, Agent schemas, AI Sessions, Checkpoints, Artifacts, and Replays are rejected without conversion, deletion, overwrite, or state change.

Field Artillery and v1.6.4 changes

fieldArtillery is an Army Base-only one-turn Recruit/Packed unit: HP25, population5, Vision5, stores100/100, fixed ammunition upkeep1. Reservation costs population5, Civilian100, Military200 and Fuel100 including initial stores. The shared lifetime production limit is two, counting pending reservations and placement; death never releases a completed slot. Public productionLedger reports completed/reserved/limit/remaining.

ChangeUnitMode {unitId,mode:"packed"|"deployed"} requires an unused turn, costs nothing, and locks movement and all attacks/reactions until next Player Turn. Packed has Move10, Range1, Attack7/9/9, ammunition4, Fuel10 per MP and emergency MP1. Deployed has Move0, inclusive Range10–200, Attack40/50/50, ammunition50 minimum, and no automatic reactions. One charge at every proficiency. Artillery cannot capture, recover, suppress or contain; destruction reanimates one Soldier Zombie.

AttackHex {attackerId,position:{q,r}} targets any currently visible Hex, including water, empty ground and internal infection. Attack also accepts visible enemies. Recruit/Regular hit50% and otherwise scatter uniformly within distance1–2/1, excluding the center; Veteran hits100%. All direct/full and adjacent/half terrain-adjusted damage resolves before Gas chains. Friendly units and every internal population pool are vulnerable; no building HP is added. Gas explosion base damage is Human30/Zombie15. Source and impact noise each have radius40 with one reaction per recipient and source priority on overlap.

Revision-pinned preview supplies typed artillery probabilities, possibleImpactHexes, possibleBlastHexes, friendlyFirePossible, friendlyUnitIdsAtRisk, unitRisks, populationRisks, terrain multipliers and known Gas-chain risks. Unknown neutral counts stay unknown; preview never reads execution RNG. Human UI requires collateral confirmation. Built-in AI normally avoids collateral and permits an emergency only when all five public conditions hold: imminent site fall, no adequate alternative, improved defense probability, fewer expected people lost by next Player Turn, and no possible immediate defeat. Unsupported estimates deny the exception; Core does not impose this strategy on external AI.

Ruined checkpoints automatically recover with zero infection, no enemy on the same Hex and a capable garrison; adjacent enemies do not block recovery. Recovery assigns Active/Standby/Dormant according to branch capacity. RelocateCheckpoint requires checkpointId and position; branchId is optional and inferred, with mismatches rejected. Player Recon uses the common Human route boundary. Display name Soldier retains internal nationalGuard.

Live and Replay share the public board, terrain/roads/bridges/FoW, mode assets, entity details and pan/zoom/fit. Frames preserve selection/viewpoint and clear unavailable entities. Action Schema is2.0.0 and Query Contract1.1.0; Play-turn1.2.0, AiSession1.1.0 and ZIP/Store1.0.0 envelopes are unchanged. For complete commands and strategy, read PLAY_WITH_AI.md.

Public forecasts and queries

Forecasts include maintenance population (city/housing residents, facility workers, units, and all three healthy checkpoint queues), base upkeep, overcrowding, and housing outage costs. Facility details distinguish recovery from production requirements. Lethal Gas attack previews include currently public immediate chains, damage, and infection; hidden and later enemy-phase consequences are not predicted.

query --target=population-transfers returns Core-validated source/destination pairs, integer bounds, reasons, and Revision. Submit any legal integer within the range using TransferPopulation; the legal-action list is a finite set of examples. Always revalidate with the current Revision. Construction queries support facilityType, legalOnly, inSupply, reasonCode, and coordinate filters.

Recorded roads contain explicit trunk/collector/access edges. All road destination Hexes cost MP 1 while terrain defense, Supply, and trunk-only checkpoint qualification remain unchanged. Session artifact export also returns a self-contained public ZIP for the title screen's read-only AI replay viewer. Use the Portable ZIP, not a Browser Bridge JSON artifact.

Current rules visible to agents

  • The five fixed Waves occur on Turns 10, 20, 35, 50, and 70. Direction counts are 1/2/1/3/4, Horde Zombies per direction are 5/3/8/5/8, and special slots per direction are 3/5/7/7/8. All Waves use the same weights: Horde 65, Police 10, Soldier 10, Riot 5, Hunter 5, Screamer 5 and Gas 5. Normal results become actual Horde Zombies, including rejected-refugee bonus slots. Gas has no direction cap; Riot and Hunter retain theirs. Public names are variantSlotCountPerDirection, possibleVariantTypes, and extraWaveSlots.
  • Exactly one Oil Field is selected independently and deterministically from four map candidates. The shared national Refinery Allowance starts at 2000; Oil Field workers add credits and actual refining consumes them. Agent facility data exposes the selected public Oil Field and shared allowance ledger.
  • Every initially neutral permanent Facility may contain early-capture survivors. Before capture, the public API exposes only whether the opportunity is possible or lost—never exact count, roll range, deadline, or aggregate values that reveal them. A capture event first reveals the rescued count. Unsecured Army Base interceptions are public only when the base is visible and expose no survivor count or dedicated-store details.
  • Tiles expose Plain/Forest/Mountain terrain, road and urban overlays, weighted movement cost, terrain defense, current player visibility, and playerOccupancyAllowed. The outer two rows/columns form a 392-hex Horde Spawn Reserve with player occupancy disabled: Player Units, Player facilities, and Checkpoints cannot enter, stop, or be placed there, while Zombie movement, attacks, damage, interception, and attacks against visible Zombies remain legal.
  • Enemy arrays contain only visible Normal, Horde, Police, Soldier, Riot, Hunter, Gas, Screamer and Pack Zombies. Hidden positions, IDs, target memory, and exact spawn coordinates are not exposed through observations, legal actions, events, or the bridge.
  • Hunter has HP 20, Attack 15, Movement 15, Range 1, Vision 5, and one Attack Charge. It uses Normal AI, including Noise, inherited Horde targets, and idle behavior. In addition to 40 initial Normal Zombies, each seed places 4 Hunters, 4 Gas and 2 Screamers at least 20 Hexes from the Capital. All initial Normal, Hunter, and Gas Zombies start farther from the Army Base than their own Vision. These initial draws and positions remain private until observed.
  • Horde has HP 40 and four shared Attack Charges for attacks, counterattacks, and interceptions. It can attack repeatedly while charges and legal targets remain, re-evaluating nearby targets after each combat, with at most one movement. Charges refill at Player Turn Start, not again at Zombie Phase Start. Normal Zombie HP is 15 and Riot Zombie HP is 60. Wave special Zombies retain a private wave_capital anchor after visible population and before Noise; its coordinates and each Zombie's target state are not exposed. getApiInfo().rules.zombies exposes all current configured stats.
  • Player Units, the Capital (radius 5), owned facilities, and Active checkpoints provide Ground Vision. Forest and Mountain are visible blockers and hide Hexes beyond them. Powered Civilian Drone Bases provide terrain-ignoring Aerial Vision. Human UI and Agent API consume the same Core coverage sets.
  • Each scheduled Wave freezes a roster at its scheduled turn, then spawns Pending entries across later Horde phases as each 22-hex direction zone has space. Direction/group entries in horde.waves, and wave-wide totals in horde.waveTotals, expose baseWaveUnitCount, committedWaveUnitCount, spawnedSoFar, and pendingCount. horde_wave_started fires once per frozen direction/group; each actual spawn has a horde_spawn_batch event with spawnedThisBatch. finalPendingCount prevents a false Final-Horde-clear reading. Rejected counters, Pending Type breakdowns, and hidden Spawn positions remain private.
  • Initial Normal Zombies use 40 deterministic Seed-selected positions at least 8 Hexes from the Capital, preferring positions off and non-adjacent to the four main road trunks, outside facilities, initial Human Units, and the Reserve. A fallen site converts each 5 actually infected people into one Zombie, up to 6 per resolution, on empty passable adjacent Hexes. Noise-driven fallen-site respawns draw Normal/Gas/Hunter/Screamer at 70/10/10/10. Generated occupancy and FIFO chains resolve immediately and atomically, but generated Zombies wait until the next Zombie phase to act normally.
  • importantSiteEvents exposes the latest 50 public infection onset, fall, spawn, immediate infection, chain, and Noise-respawn facts even off-screen. It never exposes generated Zombie IDs, exact Spawn Hexes, targets, or hidden Noise reactions.
  • At the next player-turn start, supplied surviving units recover 5% of max HP after attack, counterattack, interception, or suppression, and 10% after only moving, waiting, or taking no action. Out-of-supply units recover 0%; configured rounding is applied.
  • A human unit with the containment capability stationed at an infected location contains internal spread. With an unused attack and at least 1 carried Military Good after refill, automatic suppression consumes 1 in the infection phase after End Turn. At 0, the unit only contains spread and does not spend its attack. Police suppress without civilian damage; Soldier suppresses more but has civilian damage.
  • Each human unit exposes currentMilitaryGoods, maxMilitaryGoods, fixed consumption, distance-based attack costs, suppression cost, refill projections, and carried totals after fixed consumption, refill, and suppression. The removed global militarySupplyAvailable flag is not part of this contract.
  • Police, Riot Police, and Soldier distance-1 attacks cost 2 carried Military Goods. With only 0 or 1, they spend the remainder and attack at 20% of current attack, rounded up with minimum 1. Soldier distance 2 costs 4. Recon attacks at any distance 1–6 cost 6 and are illegal below 6. Each legal attackPreviews entry exposes distance, cost, projected balance, effective attack, and damage before/after terrain.
  • Unit observations expose baseRange, effectiveRange, and shortage reasons. Recon has HP 25, Recruit Attack 9, Regular/Veteran Attack 12, Movement 10, Vision 10, Range 6, Fuel 44, carried Military Goods 40, and public Noise class medium. It can be produced at the Capital and Army Base and reanimates as one Soldier Zombie.
  • Capital and City demand 10 power; Civilian Factory 15; Military Factory 20; Refinery 10; Temporary Housing 5. Power Plant generates 15 per worker. Required facilities stop their powered output when unpowered while city administration and population remain.
  • Police has Movement 15; Soldier, Riot Police, and Recon have Movement 10. Police/Riot Fuel capacity is 24 and Soldier/Recon capacity is 44. Normal movement Fuel cost is twice the pre-v1.6.1 terrain formula. With Fuel 0, Emergency Movement remains available. Legal Move previews expose movementMode, effectiveMovementCost, and projected Fuel.
  • End Turn uses Fuel for Power first, then refills supplied units in Unit-ID round-robin order; same-turn Refinery output is not available. Separately, Soldier consume 1 carried Military Good, Military Factory output enters national stock, and supplied units refill carried goods in Unit-ID ascending round-robin order before automatic suppression.
  • Each operational Wind provides 15 Electricity without Fuel, Vision 1, and one Noise Pulse at the public static getApiInfo().rules.constructibleFacilities.windPowerPlant.noiseRadius. Player-built Wind costs 150 Civilian Goods, has Zombie Target Value 0, can be built up to twice the road-branch count, and continues generating while disconnected from Supply. Building, disabled, and recovering Wind generates no power or Noise.
  • BuildConstructibleFacility can build Simple Farms, Civilian Drone Bases, Temporary Housing, or Wind on supplied empty Plain Hexes with no trunk road, urban overlay, entrance, player unit, or visible Zombie. Build candidates are Core-derived and hidden Zombies never alter their legality.
  • Simple Farm and Temporary Housing each cost Civilian Goods 50 and have no build-count limit. Housing has hard capacity 10 healthy plus infected residents, Vision1, power demand5, no production and no recruitment. Occupied Housing retains distinct power/supply outage forecasts. Drone and Wind count limits remain unchanged.
  • Power uses turn-start Fuel only at Fuel 2 → Electricity 5, with no partial allocation. Order is Capital/City, occupied Temporary Housing, permanent Farm/Civilian Factory, input-ready Military Factory, Refinery, Drone Base, Army Base reservation, then empty Temporary Housing.
  • strategicForecast exposes dependency contributors, current shortages, single points of failure, Guaranteed Defeat, Fuel accounting, and productionCapacity. For Food, Civilian Goods, Military Goods, and Fuel it reports the next End Turn's projected output, installed and resident-rated bounds, gap, a utilization ratio that is null when no rated capacity exists, and overlapping blocking-reason counts. Installed capacity includes player-owned completed unruined facilities even when temporarily inactive; it excludes unowned, under-construction, and ruined facilities. Its bounds use current healthy city residents and do not promise a simultaneous allocation across shared population, power, and input stocks; feasibleHeadroom is not_computed. Electricity instead reports available generation, demand, allocation, and unallocated capacity, and cannot be stored. Compact Session responses retain the required resource summary; a revision-bound query forecast adds intermediate stages, the null-utilization reason, and per-facility inactive reasons. Public Artifact Metrics include power requested/supplied/unavailable/OFF turns, resource loss, Checkpoint queue capacity/throughput, public frozen-Wave totals and Final Horde progress without hidden IDs, coordinates, or Type breakdowns. Checkpoints expose branch policy and currentPolicyTurns, queue totals, throughput, arrival ranges, and Queue Pressure (none, low, medium, high).
  • Each road branch exposes one Active post, zero or more Standby and Dormant posts, a structural fallback flag, branch policy, and its prepared-post limit. Only Active posts receive arrivals, provide supply, and provide checkpoint vision. Fallback considers capital-side Standby first, then Dormant, without revealing hidden-Zombie exclusions.
  • checkpointPositionCandidates contains every branch road tile or activatable post with actionType, branchId, optional checkpointId, position, legal, and a Core reasonCode. Build and relocation require the destination and the entire capital-side road corridor through it to be in current Player Vision. Permanent and constructible Facility Hexes are ineligible. Use the candidates instead of reconstructing legality.
  • Checkpoint candidates include projected radius, supplied/unsupplied hex and facility deltas, and newly buildable constructible Hex count. Hidden enemies neither block candidates nor appear through IDs, messages, or candidate differences.
  • Checkpoint policy belongs to the branch and follows its Active post. Policy details describe screening time, acceptance, infection chance, and infected share. Switching to deny preserves existing waiting people under their grandfathered prior policy while automatically turning away only later arrivals. Waiting above 100 reserves next-turn infection risk at one percentage point per excess person, capped at 100%; the percentage is public but the unresolved infection draw is not. A listed TurnAwayCheckpointRefugees action can remove waiting refugees, but direction/policy rejection counters and the calculated future Horde bonus are never exposed.
  • DecommissionConstructibleFacility can remove an eligible player-owned Civilian Drone Base or empty Temporary Housing. The Core validates all conditions and applies the deterministic Drone refund; Temporary Housing refunds 0. Simple Farm and Wind Power decommissioning are not legal.
  • A Combat Noise event exposes its Human Unit type and public class only. Police, Riot Police, and Recon are medium; Soldier is large. A Screamer that first acquires visible population or an inherited Horde target screams once; Horde-derived Screamers scream immediately after placement. The public event exposes only class extraLarge, never source, position, or exact radius. Fallen permanent sites can respawn from Noise. Pulse centers, exact radius, affected Zombie IDs/counts, Spawn Hexes, and Zombie Noise Targets are not public.

Available methods

getApiInfo(), reset(options?), getObservation(), getLegalActions(), step(action), isGameOver(), getResult(), getRunArtifact(), and getArtifactPage(options?).

Call getApiInfo() for machine-readable versions, schemas, the recommended order, and the complete minimal example. Every returned value is a JSON-compatible copy. The bridge never reads or writes localStorage, save codes, or the normal UI session.

Persistent AI Portable Sessions

The downloadable AI Portable package provides play-turn as the standard way to operate one player turn in one Node process. Linux uses ./run-session.sh play-turn --session=my-game; Windows uses run-session.cmd play-turn --session=my-game. It writes JSON Lines: a start record, read-only query and revision-bound action records, then one closed record. Each action includes a unique 1–128-code-point requestId; resending the same content replays the original result, while changed content with the same ID is rejected. Explicit EndTurn closes a successful turn. EOF, timeout, and an explicit close never end the game turn automatically.

For a bounded non-interactive turn, pass a finite action plan with --input=turn-plan.json. The plan stops after a rejected action, interrupted Move, unexpected unit damage or loss, a newly visible enemy, a new or worsened public crisis, Game Over, or End Turn, and reports which indexes ran. The protocol bounds a JSONL line, a finite plan, and requests per process; it also honors stdout backpressure. --help and query api expose the exact limits and capabilities.

The eight legacy persistent commands remain available: new, status, query, step, save-checkpoint, list-checkpoints, load-checkpoint, and artifact. Responses default to Compact; use read-only query to retrieve public details in revision-bound pages (100 items by default, maximum 500), or a complete public snapshot. A step requires one legal action and a 1–500-code-point public decisionSummary. An optional expectedRevision rejects stale input without consuming a decision. load-checkpoint creates a separate child Session.

Public Decision Logs preserve observations, legal actions, input summaries, acceptance/errors, events, and hash-chain links using compressed snapshots and lossless diffs. Public artifacts export a self-contained package with shared immutable ancestry and streamed verification/replay. Save Format 21 private state exists only for deterministic resume and is excluded from public exports. Active corruption is never silently rolled back. See PLAY_WITH_AI.md for commands and recovery guidance.

Minimal browser example

const api = window.NLTH;
const info = api.getApiInfo();
console.log(info.appVersion, info.rules);
api.reset({ seed: 1, agent: { id: 'browser-agent' } });
while (!api.isGameOver()) {
  const legal = api.getLegalActions();
  if (legal.length === 0) break;
  api.step(legal.find(action => action.type === 'EndTurn') ?? legal[0]);
}
console.log(api.getResult(), api.getArtifactPage({ target: 'manifest' }));

Browser smoke check

Build the production bundle, then run the dependency-free static bridge smoke check:

npm run build
npm run test:browser-bridge

A real browser can additionally open the GitHub Pages game URL, evaluate window.NLTH.getApiInfo(), reset a seed, fetch observations and legal actions, correct an invalid action, then replay listed actions until Game Over and collect Result／Artifact. A winning run is not required for this smoke check.

External-agent checklist

  • Discover the bridge from this page and the game URL without UI clicks or query parameters.
  • Read API information, observation, and legal actions before choosing one action per step().
  • After an invalid action, read its error, choose a listed legal action, and continue until Game Over.
  • Collect the result and Browser Bridge artifact as a public play trace; Artifact Schema 18.0.0 stores fixed-map topology once and each trace entry refers to it by mapId. Public Wave/Warning/Site Event state and release Metrics remain available without exposing verificationEvents, rejected-refugee counters, exact neutral-survivor state, Pending roster types, Screamer source/radius, or hidden Spawn Hexes. Session artifacts can also carry Public Decision Log and lineage. Neither contains private GameState or hidden chain of thought.

Not exposed

getState, LoadSnapshot, arbitrary code execution, file operations, save operations, local storage, network access, Batch execution, exact active-Pulse radius, and hidden Noise reactions are not part of the public bridge. The configured Wind Noise Radius is a public static rule.
